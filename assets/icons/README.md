# App icon variants

One folder per variant: `assets/icons/<id>/` with `source.svg` (or `source.png`),
`preview.png` (in-app picker) and `window.png` (Linux window icon). Generated by
`python3 tool/gen_icons.py`.

To add a variant `foo`:

1. Add the source and an entry in `tool/gen_icons.py`.
2. Add `foo(...)` to `AppIconStyle` in `lib/services/app_icon_service.dart`
   (list order = Windows resource order; the default stays first).
3. List `assets/icons/foo/` under `flutter: assets:` in `pubspec.yaml`.
4. Native registration, named after the capitalized id (`Foo`):
   - Android: `<activity-alias android:name="com.sillygru.wispie.IconFoo">` in
     `AndroidManifest.xml` (disabled) plus `mipmap/ic_launcher_foo*` resources.
   - iOS: `AppIconFoo.appiconset`, appended to
     `ASSETCATALOG_COMPILER_ALTERNATE_APPICON_NAMES` in `project.pbxproj`.
   - macOS: `IconFoo.imageset` in `Assets.xcassets`.
   - Windows: `app_icon_foo.ico`, and `IDI_APP_ICON_FOO` = 101 + its index in
     `resource.h` / `Runner.rc`.
   - Linux: nothing beyond `window.png`.
